식당 웨이팅 관리 웹앱
=======================

파일
- index.html: 웨이팅 관리 웹앱

1) 바로 테스트하기
index.html을 브라우저에서 열어 등록/호출/입장 완료/취소 기능을 테스트할 수 있습니다.
이 모드는 현재 휴대폰 브라우저에만 저장되므로 다른 휴대폰과 동기화되지 않습니다.
모듈 스크립트와 Firebase CDN 사용 때문에, 권장 실행 방식은 아래의 정적 웹 호스팅입니다.

2) 인터넷 주소로 배포하기
GitHub Pages, Firebase Hosting 등 정적 호스팅에 index.html을 올리세요. 앱 설치는 필요 없습니다.
무료 호스팅 서비스의 현재 요금/제한은 제공자 사이트에서 확인하세요.

3) 여러 휴대폰 실시간 동기화 (Firebase Realtime Database)
- Firebase Console에서 프로젝트 생성
- 프로젝트 설정 > 내 앱 > 웹 앱 추가 후 웹 앱 설정값 확보
- Authentication > Sign-in method에서 Anonymous(익명) 로그인 활성화
- Realtime Database 생성
- Database > Rules에 데모용 규칙 설정 후 게시:

{
  "rules": {
    "waitingRoom": {
      "shared-v1": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}

주의: 위 규칙은 데모용입니다. 익명 인증이 켜져 있으면 데이터베이스 경로를 아는 사용자가 접근할 수 있으므로, 실제 영업장 고객정보/개인정보에 그대로 사용하지 마세요. 실제 운영 전에는 관리자 로그인, 권한 분리, 데이터 접근 제한을 적용하세요.
- index.html의 '여러 휴대폰 동시 사용 설정'을 열고 apiKey, authDomain, databaseURL, projectId, appId를 입력
- 같은 설정을 모든 직원 휴대폰에서 입력
- 각 휴대폰에서 같은 웹 주소로 접속하면 같은 웨이팅 목록을 실시간 공유

기능
- 대기 등록 (이름/별칭, 인원, 메모)
- 자동 대기번호
- 다음 팀 호출 및 개별 호출
- 입장 완료, 취소, 기록 삭제
- 현황 카운트 및 목록 필터
- 화면에서 직접 호출 (문자 발송은 하지 않음)

개인정보 안내
고객 전화번호는 현재 입력 항목에 포함하지 않았습니다. 실명 대신 별칭을 사용하고 필요한 정보만 기록하세요.
