여러 휴대폰 동시 사용 설정
현재는 설정 없이 바로 쓸 수 있는 단일 기기 모드입니다. 여러 휴대폰에서 실시간으로 같은 목록을 보려면 Firebase 무료 프로젝트 설정이 필요합니다. 아래 값을 입력하고 저장한 뒤, 같은 설정을 각 휴대폰에 입력하세요.
Firebase 준비 순서
1. Firebase 콘솔에서 프로젝트를 만들고 웹 앱을 추가합니다.
2. Authentication에서 익명 로그인을 켭니다.
3. Realtime Database를 만들고, 아래 안내 파일의 보안 규칙을 설정합니다.
4. 위 웹 앱 설정값을 입력합니다. 모든 기기에 같은 설정을 넣어야 합니다.

주의: 아래 예시 보안 규칙은 링크를 아는 사용자가 익명 인증 후 데이터를 읽고 쓸 수 있는 데모용입니다. 실제 영업장 운영 전에는 접근 통제를 강화하세요.

사용 안내

• 대기번호는 등록 순서대로 자동 부여됩니다.
• '다음 팀 호출'은 가장 오래 기다린 대기 팀을 호출 상태로 바꿉니다.
• 브라우저 데이터 삭제 시 로컬 기록이 사라질 수 있습니다. 여러 기기 동기화는 Firebase 연결 후 사용할 수 있습니다.
• 이 웹앱은 고객에게 자동 문자/알림을 보내지 않습니다. 직원이 화면을 보고 직접 호출하는 용도입니다.
